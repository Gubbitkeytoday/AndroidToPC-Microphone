# Changelog

All notable changes to **Android to PC Microphone** are documented here.

## [1.0.0] - 2026-08-20
### Added
- **Zero-Install Web Audio PWA**: Mobile web client capturing 48kHz / 16-bit uncompressed PCM audio.
- **Binary WebSocket Audio Hub**: Express + `ws` server broadcasting binary PCM audio buffers.
- **Python Virtual Audio Cable Bridge**: PyAudio stream receiver feeding Windows VB-Audio Virtual Cable for Discord & OBS.
- **Real-Time VU Meter & Pre-Amp Gain**: Live decibel meter and pre-amplification boost slider.
